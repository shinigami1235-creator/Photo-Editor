# Photo Editor models

Model files Photo Editor downloads on first use. Kept on this branch so the main branch stays small.

| File | What it is | Licence |
| --- | --- | --- |
| `face/restoreformer-pp-fp16.onnx.part0` and `.part1` | RestoreFormer++ for Enhance faces, converted to ONNX with the debug outputs removed and the weights at half precision. Join the parts in order. | Apache 2.0, from wzhouxiff/RestoreFormerPlusPlus |

`face/restoreformer-pp-fp16.onnx.sha256` is the SHA-256 of the joined file.
